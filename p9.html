```html HTML, CSS e JavaScript — Dois Lados

🌸 O Lado Bonito da Web

HTML cria a estrutura.
CSS deixa tudo bonito.
JavaScript faz tudo interagir.

🦴 HTML — O Esqueleto

HTML é como o esqueleto de uma página.

Ele organiza os elementos que existirão dentro da página.

<h1>Título</h1>
<p>Meu texto</p>

🎨 CSS — A Aparência

CSS é responsável pela aparência.

É como comparar uma pessoa: o HTML seria sua estrutura, enquanto o CSS cuidaria das cores, roupas, aparência e estilo.

color: pink;
font-size: 20px;
border-radius: 20px;

⚡ JavaScript — A Ação

JavaScript permite que a página reaja às ações do usuário.

Por exemplo: quando o mouse passa sobre alguma coisa, podemos alterar cores, tamanho, imagens e filtros.

mouseover
mouseout
onclick

🏷️ Algumas Tags

<strong> deixa o texto em negrito.

<em> deixa o texto em itálico.

<br> quebra a linha.

<p></p> cria um parágrafo.

<img> insere uma imagem.

🖼️ <img>

A tag <img> é uma tag vazia: ela não precisa de uma tag de fechamento.

Passe o mouse sobre a imagem!

☠ O Lado Sombrio da Web

A mesma estrutura pode receber uma aparência completamente diferente.

💀 HTML continua sendo o esqueleto

Mesmo que a página fique assustadora, o HTML continua organizando tudo.

<h1>Terror</h1>
<p>Algo está aqui...</p>

🩸 CSS pode transformar tudo

Com CSS podemos transformar uma estrutura simples em algo sombrio.

background: #050505;
color: #ff4444;
box-shadow: 0 0 20px black;

👁 JavaScript pode reagir

Passe o mouse sobre este cartão.

O JavaScript pode perceber ações como mouseover e mouseout.

🕷️ Tags também possuem funções

<strong> = negrito

<em> = itálico

<br> = quebra de linha

<p> = parágrafo

👻 Uma imagem pode mudar

Passe o mouse sobre ela...

```
